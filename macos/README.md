# RedCast для macOS

Инструкция по установке и использованию.

<br clear="left">

RedCast слушает созвон (Zoom, Google Meet, Teams, Telegram, браузер), распознаёт русскую и украинскую речь прямо на Mac и за 1–3 секунды показывает подсказку с ответом. Окно не видно собеседнику при демонстрации экрана.

**Что нового в версии 2**
- Всё в одном окне: вкладки «Подсказки» и «Настройки», отдельного окна настроек больше нет.
- Окно сворачивается в тонкую полоску (кнопка **—**) и прячется целиком (кнопка **✕**).
- Большая кнопка **«Старт»**. Если что-то мешает запуску, наверху появляется жёлтая плашка с причиной.
- Режим **«По кнопкам»**: кнопки «Интервьюер» и «Я». Первое нажатие начинает запись, второе даёт ответ.
- Любую горячую клавишу можно переназначить.
- Подсказка отвечает только на новый вопрос и больше не путает его со старыми.
- Голос интервьюера из динамиков больше не записывается как ваш: работают эхоподавление и фильтр повторов.

---

## 1. Что нужно
- Mac на **M1 или новее**, **macOS 14** или новее.
- Около 3 ГБ свободного места.
- Подписка **Claude Pro/Max** или **API-ключ** Anthropic.
- Желательно наушники.

---

## 2. Установка

### Готовое приложение (рекомендуется)
1. Скачайте **[RedCast-macOS.zip](https://github.com/Shelt00n/RedCast/releases/latest/download/RedCast-macOS.zip)** из последнего релиза.
2. Дважды щёлкните по архиву и перетащите **RedCast.app** в папку **«Программы»**. Если там была старая версия, замените её.
3. Приложение не подписано платным сертификатом Apple, поэтому один раз снимите «карантин» в Терминале (⌘ + Пробел → «Терминал»):
```bash
xattr -dr com.apple.quarantine /Applications/RedCast.app
```
4. Запустите RedCast из «Программ». В строке меню появится значок волны, а справа вверху — окно.
5. При первом запуске скачается модель распознавания речи, около 1,6 ГБ, один раз.

> **После каждого обновления** macOS сбрасывает разрешение на звук для новой версии. Откройте «Системные настройки» → «Конфиденциальность и безопасность» → **«Запись экрана и системного звука»**, удалите RedCast кнопкой **«−»**, добавьте снова кнопкой **«+»** и перезапустите приложение. Чаще всего «Старт не работает» именно из-за этого.

### Сборка из исходников (для разработчиков)
Нужен Xcode 16+.
```bash
git clone https://github.com/Shelt00n/RedCast.git
```
```bash
cd RedCast/macos && bash build_app.sh
```
Готовое приложение появится в `macos/build/RedCast.app`.

## 3. Подключение Claude

Откройте окно RedCast → вкладка **«Настройки»** → раздел **«1. Подключение Claude»**.

### Вариант А. API-ключ (быстрее, лимиты подписки не тратятся)
1. На **platform.claude.com** → **Billing** пополните баланс (от $5).
2. **API Keys** → **Create Key** → скопируйте ключ `sk-ant-…`.
3. В RedCast выберите «Anthropic API» и вставьте ключ (⌘V).

Час собеседования стоит примерно $1–3.

### Вариант Б. Подписка Claude Pro/Max
Один раз выполните в Терминале:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```
```bash
claude
```
Внутри наберите `/login`, войдите в аккаунт, затем наберите `/exit`. В RedCast выберите «Подписка Claude Pro/Max». Учтите, что лимит общий с приложением Claude.

**Дальше:** «Глубина размышлений» → `low`, затем нажмите **«Проверить соединение»**. Во вкладке «Подсказки» должно появиться «работает».

## 4. Настройка (вкладка «Настройки»)

| Раздел | Что сделать |
|---|---|
| 2. Распознавание речи | Выберите язык (Русский / Українська), заполните словарь терминов (стек, компании, имена) |
| | **Режим**: «Авто» или «По кнопкам» (подробно в разделе 5) |
| | Включите **эхоподавление**, если собеседуетесь без наушников |
| 3. Профиль | Вставьте резюме («Из файла…» понимает PDF) и вакансию |
| 4. Окно | Прозрачность, размер шрифта, скрытие при демонстрации экрана |
| 5. Горячие клавиши | Нажмите на сочетание и введите новое (подробно в разделе 6) |

## 5. Как пользоваться

### Режим «Авто»: RedCast сам слышит вопросы
1. Зайдите в звонок и нажмите зелёную кнопку **«Старт»**.
2. Интервьюер задаёт вопрос и делает паузу. Через 1–3 секунды появится подсказка.
3. **«Ответить сейчас»** выдаёт подсказку сразу, не дожидаясь паузы.
4. Кнопка **«Стоп»** завершает сессию, расшифровка сохраняется.

### Режим «По кнопкам»: вы сами решаете, что считать вопросом
Здесь нет путаницы и ответов на старые вопросы.
- **🎧 Интервьюер** (⌃⌥1): нажмите, когда интервьюер **начал** вопрос, и ещё раз, когда **закончил**. Через 1–3 секунды появится ответ именно на этот вопрос.
- **🎤 Я** (⌃⌥2): то же для вашего микрофона. Можно вслух повторить вопрос («Вы спрашиваете про…»), и RedCast ответит на него. Можно начать отвечать, и RedCast подскажет, что добавить.

Пока идёт запись, кнопка красная, а внизу видна живая расшифровка.

### Подсказка
- **Жирная первая строка** — главная мысль, её можно говорить сразу.
- Ниже 2–5 пунктов, код или структура STAR.
- Цифра справа (например, «1.8 с») — сколько секунд прошло до появления ответа.

### Всегда доступно
- **📷 Скриншот** (⌃⌥S): решение задачи с экрана (live coding, тест).
- **Поле внизу:** вопрос можно ввести текстом и нажать Enter.
- **—** свернуть окно в полоску, **✕** скрыть его. Вернуть окно можно через значок волны в строке меню или ⌃⌥H.
- Окно перетаскивается за шапку или панель кнопок. Размер меняется за **любой край и угол**. Быстрые размеры есть в меню «Размер окна» (строка меню на Mac, трей на Windows).
- Старые ответы сворачиваются в одну строку, клик по заголовку разворачивает их обратно.

## 6. Горячие клавиши

По умолчанию все начинаются с **⌃ Control + ⌥ Option**:

| Клавиши | Действие |
|---|---|
| ⌃⌥ **1** | По кнопкам: записать интервьюера → ответ |
| ⌃⌥ **2** | По кнопкам: записать меня → ответ |
| ⌃⌥ **L** | Авто: старт / стоп |
| ⌃⌥ **Space** | Ответить сейчас |
| ⌃⌥ **S** | Скриншот → решение |
| ⌃⌥ **H** | Скрыть / показать окно |
| ⌃⌥ **M** | Свернуть / развернуть |
| ⌃⌥ **↑ / ↓** | Прокрутка подсказки |
| ⌃⌥ **T** | Сквозные клики |
| ⌃⌥ **.** | Остановить ответ |
| ⌃⌥ **X** | Очистить |

**Как переназначить:** «Настройки» → «5. Горячие клавиши» → нажмите на сочетание → нажмите новое (например ⌘⇧1). Esc отменяет ввод, ✕ убирает сочетание, «Сбросить» возвращает всё как было. Значок ⚠ означает, что сочетание уже занято другой программой.

## Обновление

RedCast обновляется сам: при запуске и каждые 6 часов он проверяет GitHub. Если вышла новая версия, вверху окна появляется зелёная плашка **«Доступна новая версия → Обновить»**. Нажмите её, и RedCast скачает обновление, заменит себя и перезапустится. Настройки, резюме, ключи и модель речи сохраняются. Проверить вручную можно в «Настройки» → **«6. Обновления»**.

На Mac приложение подписывает себя постоянным локальным сертификатом («RedCast Local Signing» в связке ключей). Поэтому после обновлений разрешение «Запись экрана и системного звука» больше не слетает. При первом запуске версии 2.1.0 RedCast один раз перезапустится сам, после этого выдайте разрешения в последний раз.

## 7. Если что-то не работает

| Проблема | Решение |
|---|---|
| «Старт» ничего не делает | Посмотрите на жёлтую плашку вверху окна. Если пишет «Скачивание модели…», дождитесь окончания, прослушивание начнётся само |
| Плашка «Нет доступа к звуку системы» | Нажмите кнопку на плашке, удалите и снова добавьте RedCast в «Запись экрана и системного звука», перезапустите |
| Нет текста «Интервьюер: …» | То же самое. И проверьте, что звук созвона действительно идёт через Mac |
| Отвечает на старые вопросы | Перейдите в режим «По кнопкам» |
| Мои слова подписаны как «Интервьюер» и наоборот | Наденьте наушники и включите эхоподавление. Или используйте режим «По кнопкам» |
| Эхоподавление делает звук созвона тише | Выключите его в настройках и используйте наушники |
| `command not found: claude` | Выполните команду с `export PATH` из раздела 3 и откройте Терминал заново |
| Ошибка про лимит | Закончился лимит подписки: дождитесь сброса или переключитесь на API-ключ |
| Ошибка API 401 / 400 credit balance | Неверный ключ или кончился баланс на platform.claude.com |
| Не вставляется текст (⌘V) | Сначала кликните в поле ввода |
| Окно видно в демонстрации | Показывайте одно окно, а не весь экран |

Записи собеседований: «Настройки» → «Открыть папку с записями собеседований».
