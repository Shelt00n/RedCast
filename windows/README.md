# RedCast для Windows

Инструкция по установке и использованию.

<br clear="left">

RedCast слушает созвон (Zoom, Google Meet, Teams, Telegram, Discord, браузер), распознаёт русскую и украинскую речь прямо на компьютере и за 1–3 секунды показывает подсказку с ответом от Claude. Окно не видно собеседнику при демонстрации экрана.

---

## 1. Что нужно
- **Windows 10 (версия 2004 и новее) или Windows 11**, 64-бит.
- Около 3 ГБ свободного места.
- Желательно видеокарта: подойдут NVIDIA, AMD или встроенная Intel. С ней распознавание в 3–10 раз быстрее. Без неё тоже работает, но медленнее.
- Подписка **Claude Pro/Max** или **API-ключ** Anthropic.
- Желательно наушники.

---

## 2. Установка (ничего собирать не нужно)
1. Скачайте **[RedCast-Windows.zip](https://github.com/Shelt00n/RedCast/releases/latest/download/RedCast-Windows.zip)** из последнего релиза.
2. Щёлкните по нему правой кнопкой → **«Извлечь всё…»** → «Извлечь». Получится папка `RedCast`. Удобно положить её, например, в `C:\RedCast`.
3. Откройте папку и запустите **`RedCast.exe`**.
4. Если появится синее окно **«Windows защитила ваш компьютер»**, нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Это предупреждение появляется для любой программы без платной цифровой подписи.
5. Появятся окно RedCast (справа вверху) и значок в трее (справа внизу, возле часов; иногда он прячется под стрелкой **^**).
6. При первом запуске скачивается модель распознавания речи, около 0,6 ГБ. Прогресс виден вверху окна. Дождитесь надписи «Распознавание готово».

> Чтобы запускать RedCast быстрее, сделайте ярлык: правой кнопкой по `RedCast.exe` → «Отправить» → «Рабочий стол (создать ярлык)».

## 3. Подключение Claude

Окно RedCast → кнопка **«Настройки»** → раздел **«1. Подключение Claude»**.

### Вариант А. API-ключ (быстрее, лимиты подписки не тратятся)
1. На **platform.claude.com** → **Billing** пополните баланс (от $5).
2. **API Keys** → **Create Key** → скопируйте ключ `sk-ant-…`.
3. В RedCast выберите «Anthropic API — ключ» и вставьте ключ (Ctrl+V).

Час собеседования стоит примерно $1–3. Ключ хранится в зашифрованном виде в вашей учётной записи Windows.

### Вариант Б. Подписка Claude Pro/Max
1. Откройте **PowerShell**: Пуск → наберите «PowerShell» → Enter.
2. Установите Claude Code:
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
3. Закройте PowerShell, откройте его снова и выполните:
   ```powershell
   claude
   ```
   Внутри наберите `/login`, войдите в аккаунт через браузер, затем наберите `/exit`.
4. В RedCast выберите «Подписка Claude Pro/Max». Поле «Путь к claude.exe» оставьте пустым.

Лимит подписки общий с приложением Claude.

**Дальше:** «Глубина размышлений» → `low`, затем нажмите **«Проверить соединение»**. Должен прийти ответ «работает».

## 4. Настройка (кнопка «Настройки»)

| Раздел | Что сделать |
|---|---|
| 2. Распознавание речи | Язык (Русский / Українська), словарь терминов (стек, компании, имена) |
| | «Использовать видеокарту»: оставьте включённым |
| | Модель: на слабом ноутбуке без видеокарты выберите «Whisper Small» |
| 3. Профиль | Резюме и вакансия. Можно скопировать текст из PDF или загрузить .txt/.rtf кнопкой «Из файла…» |
| 4. Окно | Прозрачность, размер шрифта, скрытие при демонстрации экрана |
| 5. Горячие клавиши | Нажмите на сочетание и введите новое (подробно в разделе 6) |

**Микрофон.** Если RedCast не слышит вас: Параметры Windows → Конфиденциальность и защита → **Микрофон** → включите «Разрешить классическим приложениям доступ к микрофону». RedCast слушает **устройства по умолчанию**: звук — то, что выбрано в Windows для вывода, микрофон — то, что выбрано для ввода.

## 5. Как пользоваться

Вверху вкладки «Подсказки» есть переключатель режимов: **«Авто»** и **«По кнопкам»**.

### Режим «Авто»: RedCast сам слышит вопросы
1. Зайдите в звонок и нажмите зелёную кнопку **«▶ Старт»** (или Ctrl+Alt+L).
2. Интервьюер задаёт вопрос и делает паузу. Через 1–3 секунды появится подсказка.
3. **«⚡ Ответить сейчас»** выдаёт подсказку сразу, не дожидаясь паузы.
4. Кнопка **«■ Стоп»** завершает сессию, запись сохраняется в «Документы\RedCast Sessions».

### Режим «По кнопкам»: вы сами решаете, что считать вопросом
Здесь нет путаницы, кто говорит, и нет ответов на старые вопросы.
- **🎧 Интервьюер** (Ctrl+Alt+1): нажмите, когда интервьюер **начал** вопрос, и ещё раз, когда **закончил**. Через 1–3 секунды появится ответ именно на этот вопрос.
- **🎤 Я** (Ctrl+Alt+2): то же для вашего микрофона. Можно вслух повторить вопрос, и RedCast ответит. Можно начать отвечать, и RedCast подскажет, что добавить.

Пока идёт запись, кнопка красная и внизу видна живая расшифровка.

### Подсказка
- **Жирная первая строка** — главная мысль, её можно говорить сразу.
- Ниже пункты, код или структура STAR.
- Цифра справа (например, «1.8 с») — время до появления ответа.

### Всегда доступно
- **📷 Скриншот** (Ctrl+Alt+S): решение задачи с экрана, на котором сейчас курсор мыши.
- **Поле внизу (⌨):** вопрос можно ввести текстом и нажать Enter.
- **—** свернуть окно в тонкую полоску, **✕** скрыть его. Вернуть окно можно кликом по значку в трее или Ctrl+Alt+H.
- Окно перетаскивается за левую часть заголовка (там, где статус). Размер меняется за уголок справа внизу.
- **Выход:** правой кнопкой по значку в трее → «Выйти».

## 6. Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+**1** | По кнопкам: записать интервьюера → ответ |
| Ctrl+Alt+**2** | По кнопкам: записать меня → ответ |
| Ctrl+Alt+**L** | Авто: старт / стоп |
| Ctrl+Alt+**Space** | Ответить сейчас |
| Ctrl+Alt+**S** | Скриншот → решение |
| Ctrl+Alt+**H** | Скрыть / показать окно |
| Ctrl+Alt+**M** | Свернуть / развернуть |
| Ctrl+Alt+**↑ / ↓** | Прокрутка подсказки |
| Ctrl+Alt+**T** | Сквозные клики (окно не мешает кликать по тому, что под ним) |
| Ctrl+Alt+**.** | Остановить ответ |
| Ctrl+Alt+**X** | Очистить |

**Как переназначить:** «Настройки» → «5. Горячие клавиши» → нажмите на сочетание → нажмите новое (например, Ctrl+Shift+1). Esc отменяет ввод, ✕ убирает сочетание, «Сбросить» возвращает всё как было. Пометка «⚠ занято другой программой» значит, что нужно выбрать другое сочетание.

---

## 7. Проверка перед собеседованием
1. Включите на YouTube собеседование на русском, выберите режим «Авто» и нажмите «Старт». Внизу должен идти текст «Интервьюер: …», а после пауз — появляться подсказки.
2. Позвоните себе со второго устройства в Zoom или Meet, включите демонстрацию **всего экрана** и убедитесь, что окна RedCast не видно.
3. Если работаете по подписке, проверьте на claude.ai → Настройки → Использование, что лимит почти не израсходован.

## 8. Если что-то не работает

| Проблема | Решение |
|---|---|
| Окно «Windows защитила ваш компьютер» | «Подробнее» → «Выполнить в любом случае» |
| Антивирус удалил или заблокировал файл | Добавьте папку RedCast в исключения антивируса. Программа ловит горячие клавиши и делает скриншоты, поэтому некоторые антивирусы перестраховываются |
| «Старт» ничего не делает | Посмотрите на жёлтую плашку вверху окна. Если идёт «Скачивание модели…», дождитесь окончания |
| Нет текста «Интервьюер: …» | Звук созвона должен идти через устройство вывода по умолчанию: Параметры → Система → Звук → Вывод |
| Подсказки приходят медленно (больше 5 с) | Включите «Использовать видеокарту». Без видеокарты выберите модель «Whisper Small» |
| Отвечает на старые вопросы или путает, кто говорит | Используйте режим «По кнопкам» и наушники |
| Ошибка «Claude Code не найден» | Выполните шаги варианта Б из раздела 3 и перезапустите RedCast |
| Ошибка про лимит | Закончился лимит подписки: дождитесь сброса или переключитесь на API-ключ |
| Ошибка API 401 / 400 credit balance | Неверный ключ или кончился баланс на platform.claude.com |
| Окно видно в демонстрации | Нужна Windows 10 версии 2004 или новее. Либо показывайте одно окно, а не весь экран |
| Окно пропало | Клик по значку в трее или Ctrl+Alt+H |
| Не получается кликнуть по окну | Включены сквозные клики: нажмите Ctrl+Alt+T |
| Программа упала | Пришлите файл `%APPDATA%\RedCast\error.log` (вставьте этот путь в адресную строку Проводника) |

**Где лежат файлы:**
- Настройки: `%APPDATA%\RedCast\settings.json`
- Модель речи: `%LOCALAPPDATA%\RedCast\Models`
- Записи собеседований: `Документы\RedCast Sessions`

**Удалить:** выйдите из RedCast (трей → «Выйти») и удалите папку программы и `%APPDATA%\RedCast`, `%LOCALAPPDATA%\RedCast`.
